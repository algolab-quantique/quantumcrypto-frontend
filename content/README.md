# Content Management - Simple and Clean

## 📁 Structure

This directory contains all content for the QuantumCrypto platform in a **simple, clean structure**:

```
content/
├── en/               # English content
├── fr/               # French content
├── es/               # Spanish content
└── README.md         # This file
```

Each language directory contains **exactly 6 files**:

```
language/
├── ui.md             # User interface text (buttons, labels, messages)
├── common.md         # Common content (homepage, about, etc.)
├── bb84.md           # BB84 protocol content
├── e91.md            # E91 protocol content  
├── dps.md            # DPS protocol content
└── definitions.md    # Technical definitions
```

## How to Add Content

### 1. Choose the right file
- **UI text** (buttons, labels) → `ui.md`
- **Protocol explanations** → `bb84.md`, `e91.md`, `dps.md`
- **Homepage content** → `common.md`
- **Technical definitions** → `definitions.md`
